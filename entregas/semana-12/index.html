Organización Computacional (IS-237) — Compuertas en chips reales con Tinkercad

Instrucciones: use la notación de clase: · o nada para AND, + para OR, ' para NOT y ⊕ para XOR. En las tablas de verdad ordene las filas en binario (000, 001, …, 111). Esta semana se entregan 3 enlaces de Tinkercad, uno por circuito. Para obtener el enlace: en su diseño use "Compartir" → "Invitar personas", copie el link y péguelo en el campo de enlace de cada pregunta. Si el enlace no funciona, adjunte capturas con la simulación encendida.

Cada pregunta acepta tres formas de respuesta, combinables: texto escrito, un enlace (por ejemplo, el enlace para compartir su proyecto de CircuitVerse o Tinkercad) y uno o varios archivos: fotos o capturas (JPG o PNG), documentos de Word (DOCX) o PDF, de hasta 8 MB cada uno. Escriba su nombre completo — es el único dato que se le pide para identificar su entrega.
