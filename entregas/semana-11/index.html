Organización Computacional (IS-237) — Mapas de Karnaugh y generador/comprobador de paridad

Instrucciones: dibuje cada mapa de Karnaugh con los encabezados en código Gray (00, 01, 11, 10), marque los grupos y escriba el término de cada uno. Use la notación de clase: · o nada para AND, + para OR, ' para NOT y ⊕ para XOR. Los laboratorios de CircuitVerse pueden terminarse en casa: pegue el enlace para compartir su proyecto.

Cada pregunta acepta tres formas de respuesta, combinables: texto escrito, un enlace (por ejemplo, el enlace para compartir su proyecto de CircuitVerse: botón "Compartir" o "Share" → "Copiar enlace") y uno o varios archivos: fotos o capturas (JPG o PNG), documentos de Word (DOCX) o PDF, de hasta 8 MB cada uno. Escriba su nombre completo — es el único dato que se le pide para identificar su entrega.
