Organización Computacional (IS-237) — Símbolos estándar IEEE/ANSI e IEC, y autoevaluación de la Unidad 3

Instrucciones: dibuje los circuitos con los símbolos estándar vistos en clase (estilo distintivo IEEE/ANSI y, cuando se pida, estilo rectangular IEC: &, ≥1, =1, 1). Use la notación de clase: · para AND, + para OR, ' para NOT y ⊕ para XOR.

Cada pregunta acepta tres formas de respuesta, combinables: texto escrito, un enlace (por ejemplo, el enlace para compartir su proyecto de CircuitVerse: botón "Compartir" o "Share" → "Copiar enlace") y uno o varios archivos: fotos o capturas (JPG o PNG), documentos de Word (DOCX) o PDF, de hasta 8 MB cada uno. Escriba su nombre completo — es el único dato que se le pide para identificar su entrega.
